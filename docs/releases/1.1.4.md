# AlphaCode 1.1.4

This release improves goal verification, diagnostic privacy, model-selection
regressions, and repeatable task evaluation.

## Fixes

- Keep the selected Alphax Free automatic route pinned through rate limits.
- Preserve final diagnostics when large SDK tool results are truncated.
- Match verification execution arguments exactly while ignoring the native code
  tools' optional UI intent label. Failed relabeled reruns revoke earlier passes;
  MCP and extension inputs remain exact.
- Redact password and cookie fields in structured diagnostics and remove
  credentials, query parameters, and fragments from retry log URLs.
- Show active session titles, preserve grapheme-aware prompt-history deletion,
  and handle remote Escape/error dismissal consistently.
- Repair model-picker fixtures and buffer assertions for server-owned routes,
  error-first summaries, and wrapped skill identifiers.

## Evaluation and CI

- Add a task-evaluation runner with fresh fixtures, independent verification,
  completion receipts, checkpointed JSON reports, and process timeout cleanup.
- Add Windows/Linux evaluation-runner tests and Windows GUI diagnostic tests.
- The included two-task evaluation is a workflow smoke suite, not a comparative
  coding-quality benchmark.

## Local validation

- Library tests: 6,798 passed, 0 failed, 15 ignored.
- Local-model compatibility: 8 passed.
- Alphagrep: 45 unit tests and 6 integration tests passed.
- Evaluation runner: 14 tests passed.
- Formatting, workspace checks including tests, and strict library Clippy passed.
- Two live coding smoke tasks passed independent verification using the new
  debug binary and the Alphax Free automatic route in an isolated app home.

Release artifacts are rebuilt by GitHub Actions. Publication requires successful
CI for the exact tagged source revision and all eight platform archives. Use the
published `SHA256SUMS` to verify downloaded archives. Windows archives contain
both the CLI and its desktop host.
