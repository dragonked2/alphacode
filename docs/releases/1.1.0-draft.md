# AlphaCode 1.1.0 — draft release notes

This draft describes the release candidate in the working tree. Finalize it
against the committed revision and verified release artifacts before publishing.

## Highlights

- The Windows desktop interface includes improvements to navigation, settings,
  search, conversation rendering, and diagnostics. Its tooltip template handles
  connection-error recovery without a WPF template exception.
- Windows updates recognize the installer's default launcher directory and
  propagate the desktop host alongside the CLI into update channels. Desktop
  sessions check for releases while open; installed updates take effect after
  the desktop is restarted. Explicit update-disable settings remain honored.
- Terminal updates improve text selection, search, picker behavior, Unicode
  rendering, and the handling of long drafts.
- Alphax Free recovery limits automatic rate-limit retries and avoids choosing
  routes that are still on cooldown.
- Security workflows improve scope handling, investigation continuity, and
  the separation of observations, confirmed findings, and reportability.

## Release verification

Confirm the final change list and run the repository's required checks on the
release commit. Verify Windows Terminal input latency from console input through
frame flush while idle, after model selection, and during streaming, including
tail latency. The tag must match the manifest version, and the release workflow
requires green main-branch CI on the exact tagged commit and all eight platform
archives with checksums. Do not publish until those checks have passed.

No overall speedup or improvement in model reasoning quality is claimed without
comparative measurements. Provider availability and rate limits remain outside
the application's control.
