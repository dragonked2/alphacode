# AlphaCode 1.1.5

This release hardens mission verification, command-risk handling, tool recovery,
and the TUI help/input experience. It also adds repeatable evaluation and
latency diagnostics for more evidence-driven development.

## Highlights

- Preserve mission criteria, validation plans, checkpoints, scope reminders,
  and changed-file inventories across continuation.
- Revoke stale completion evidence after edits, failed writes, interrupted
  reruns, or mismatched verification arguments.
- Improve command-risk path handling, including rooted POSIX destructive-target
  protection.
- Add searchable help, expanded overlays, clearer controls, and frame-level
  p50/p95/p99 input-latency diagnostics.
- Improve repeated tool-failure recovery, provider aliases, Windows input
  ordering, remote key handling, and diagnostic toasts.
- Add loopback-only bounty evaluation fixtures, engineering quality guidance,
  and focused regression coverage.

## Validation

- `cargo fmt --all -- --check` passed.
- `cargo check --workspace --tests` passed.
- `cargo clippy --workspace --all-targets --all-features --locked` passed with
  `RUSTFLAGS="-D warnings"`.
- Workspace tests were attempted against the release tree but could not
  complete because the concurrent Windows test builds hit MSVC `link.exe`
  error 1104. CI remains required for final release sign-off.

Release artifacts are rebuilt by GitHub Actions. Publication requires successful
CI for the exact tagged source revision and all platform archives. Use the
published `SHA256SUMS` to verify downloaded archives.
