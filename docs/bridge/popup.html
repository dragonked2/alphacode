AlphaCode Browser Agent
A Firefox companion for AlphaCode's agentic browser workflows.
AlphaCode Browser Agent is the Firefox execution layer for AlphaCode. It connects terminal-native agent workflows to real browser tabs and pages with resilient navigation, DOM targeting, input control, frames, forms, screenshots, downloads, sessions and telemetry. Built and maintained by AliEssam.
