## Product Focus

This self-dev session was launched from the alphacode-desktop2 (greenfield desktop) context. By default, assume the user is asking about desktop2 unless they explicitly mention the TUI/CLI. Prefer desktop2 targets and commands (`selfdev build target=desktop2`, package `alphacode-desktop2`, binary `alphacode-desktop2`, launcher `~/.local/bin/alphacode-desktop2`) for builds, reloads, tests, and UI debugging.

Desktop2 is a greenfield rewrite: it talks to the alphacode runtime through the harness API bridge (`alphacode-harness-api`, `alphacode-harness-api-bridge`) instead of the legacy desktop socket path.
